# mahata/homebrew-tap

Homebrew formulae for [@mahata](https://github.com/mahata)'s tools.

## Install

```bash
brew install mahata/tap/copilotview
```

Homebrew taps this repository automatically on first install. Use the full name: Homebrew loads formulae from unofficial taps only after you trust them, and naming the formula in full trusts it. Upgrade with `brew upgrade`.

## Formulae

| Formula | Description |
| --- | --- |
| [copilotview](https://github.com/mahata/copilotview) | Browse, search and summarize past GitHub Copilot CLI sessions |

## Maintenance

`Formula/copilotview.rb` is generated by [`scripts/homebrew-formula.mjs`](https://github.com/mahata/copilotview/blob/main/scripts/homebrew-formula.mjs) in mahata/copilotview. Its Release workflow regenerates the formula for each new release, installs and tests it with Homebrew, and pushes it here, so make changes in that script rather than editing the formula directly.
